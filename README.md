# Лист персонажа D&D 5e для Owlbear Rodeo

Расширение для [Owlbear Rodeo](https://www.owlbear.rodeo): лист персонажа на русском с бросками,
которые видят все игроки комнаты.

## Возможности

- **Характеристики** — значение, модификатор, спасброски с владением.
- **18 навыков** — владение и компетентность (двойной бонус), бонус мастерства считается по уровню.
- **Бой** — КД, инициатива, скорость, пассивная внимательность, хиты с полоской, временные хиты,
  кнопки «Урон» / «Лечение» (урон сначала снимает временные хиты).
- **Атаки и заклинания** — бросок попадания и урона в один клик; после критического попадания
  урон автоматически бросается с удвоенными кубиками.
- **Свой бросок** — любые формулы: `2d6+3`, `d20-1`, `4к6` (русская «к» тоже работает).
- **Преимущество / помеха**, **скрытые броски** (🔒 видите только вы и мастер).
- **Результат на карте** (🗺) — надпись над выделенным токеном или в центре экрана, исчезает через 6 секунд.
- **Уведомление и журнал бросков** у всех игроков комнаты, счётчик новых бросков на кнопке плагина.
- **Тема** подстраивается под светлую/тёмную тему Owlbear.
- **Резервная копия** — выгрузка и загрузка листа текстом или файлом.

## Установка

1. В Owlbear Rodeo откройте профиль → **Extensions** → **Add Extension**.
2. Вставьте адрес манифеста:
   ```
   https://maxcrash72.github.io/dnd-sheet/manifest.json
   ```
3. Включите расширение в комнате.

> Если у вас стояла версия 1.x по адресу `crashmax881-sys.github.io`, удалите её и установите заново
> по новому адресу — иначе не подключится фоновая страница, которая показывает броски.
> Лист из старой версии подхватится автоматически.

## Где хранятся данные

Лист сохраняется в браузере (отдельно для каждой комнаты) и дублируется в метаданные игрока Owlbear.
Для переноса на другое устройство используйте «Резервная копия» внизу окна.

## Устройство

Сборки нет: GitHub Pages раздаёт файлы как есть, обновление — это пуш в `main`.

| Файл | Назначение |
| --- | --- |
| `manifest.json` | описание расширения для Owlbear |
| `index.html`, `js/app.js` | окно листа |
| `background.html`, `js/background.js` | фоновая страница: принимает броски, показывает уведомления и надписи |
| `js/rules.js` | правила 5e: модификаторы, бонус мастерства, навыки, хиты |
| `js/dice.js` | кубики и разбор формул |
| `js/character.js` | модель листа, проверка данных, миграция со старой версии |
| `js/storage.js` | сохранение |
| `js/rolls.js` | рассылка и показ бросков |
| `js/obr.js` | подключение SDK Owlbear (версия закреплена здесь) |
| `js/theme.js` | цвета под тему Owlbear |

## Разработка

```bash
npm test        # тесты правил и кубиков (нужен Node.js 20+)
npm start       # локальный сервер на http://localhost:5173
```

Вне Owlbear лист открывается в «режиме без Owlbear»: всё работает, но броски видны только вам.
Чтобы проверить в Owlbear, установите расширение по адресу `http://localhost:5173/manifest.json`
(предварительно поменяв адреса в `manifest.json` на локальные).

При выпуске новой версии увеличьте `version` в `manifest.json` — она же показывается в подвале листа.
