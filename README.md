# Лист персонажа D&D 5e для Owlbear Rodeo

Расширение для [Owlbear Rodeo](https://www.owlbear.rodeo): лист персонажа на русском с бросками,
которые видят все игроки комнаты.

## Возможности

Лист рассчитан на упрощённую систему на основе D&D: без классов, уровней и бонуса мастерства.

- **Характеристики** — значение и модификатор; **спасброски и все 18 навыков** равны модификатору
  своей характеристики, без дополнительных бонусов.
- **Бой** — КД, инициатива (модификатор ловкости), скорость, хиты (текущие и максимум) с кнопками «Урон» / «Лечение».
- **Дополнительные ресурсы** — мана, дзен и т. п. (до 6 штук): текущее и максимальное значение, кнопки −1/+1.
- **Атаки и заклинания** — бросок попадания и урона в один клик.
- **Свой бросок** — любые формулы: `2d6+3`, `d20-1`, `4к6` (русская «к» тоже работает).
- **Многократные преимущество и помеха** — влияют только на ключевой d20 броска: каждый уровень
  добавляет ещё один d20 (преимущество ×2 — три d20, берётся лучший). На урон не влияют.
- **3D-кубики** (🎲) — если в комнате установлено расширение
  [Dice (dnd-sheet)](https://github.com/maxcrash72/dnd-dice), броски катятся настоящими кубиками
  с физикой, и все игроки видят анимацию. Без него лист бросает сам.
- **Скрытые броски** (🔒 видите только вы и мастер), **результат на карте** (🗺) — надпись над
  выделенным токеном или в центре экрана.
- **Уведомление и журнал бросков** у всех игроков комнаты, счётчик новых бросков на кнопке плагина.
- **Тема** подстраивается под светлую/тёмную тему Owlbear.
- **Резервная копия** — выгрузка и загрузка листа текстом или файлом.

## Установка

1. В Owlbear Rodeo откройте профиль → **Extensions** → **Add Extension**.
2. Вставьте адрес манифеста:
   ```
   https://maxcrash72.github.io/dnd-sheet/manifest.json
   ```
3. Включите расширение в комнате.
4. Для 3D-кубиков добавьте так же расширение `https://maxcrash72.github.io/dnd-dice/manifest.json`
   и уберите из комнаты официальный Dice (они хранят броски под разными ключами).

> Если у вас стояла версия 1.x по адресу `crashmax881-sys.github.io`, удалите её и установите заново
> по новому адресу — иначе не подключится фоновая страница, которая показывает броски.
> Лист из старой версии подхватится автоматически.

## Где хранятся данные

Лист каждого игрока хранится **в комнате Owlbear** (метаданные комнаты), под постоянным id игрока.
Он сохраняется между сессиями: игрок может выйти, сменить браузер или устройство — при входе
в ту же комнату лист будет на месте. Копия лежит и в браузере, на случай если в комнате нет места.

**Мастер** видит в шапке список «Лист» со всеми листами комнаты, открывает и редактирует любой —
правки сразу появляются у игрока (и наоборот). Там же — «Удалить лист» и сколько места занято.

Ограничения Owlbear: все метаданные комнаты — не больше 16 КБ на все расширения. Лист хранится
в сжатом виде (обычно 1–2 КБ), поэтому заметки ограничены 1000 символами — в комнату помещается
6–7 листов. Если места не хватит, лист сохранится только в браузере, а внизу появится предупреждение.

Технически данные комнаты может прочитать любое расширение в ней — секретов в лист лучше не писать.
Листы из версий 1.x–2.x переносятся в комнату автоматически при первом открытии.
Для переноса между комнатами используйте «Резервная копия» внизу окна.

## Устройство

Сборки нет: GitHub Pages раздаёт файлы как есть, обновление — это пуш в `main`.

| Файл | Назначение |
| --- | --- |
| `manifest.json` | описание расширения для Owlbear |
| `index.html`, `js/app.js` | окно листа |
| `background.html`, `js/background.js` | фоновая страница: принимает броски, показывает уведомления и надписи |
| `js/rules.js` | правила: модификаторы, навыки, преимущество/помеха, пулы хитов и ресурсов |
| `js/dice.js` | кубики, разбор формул, запросы к 3D-кубикам |
| `js/dice3d.js` | связь с расширением Dice (dnd-sheet) через `BroadcastChannel` |
| `js/character.js` | модель листа, проверка данных, миграция со старой версии |
| `js/storage.js` | хранение листов в комнате, живое обновление, кэш в браузере |
| `js/codec.js` | сжатие листа для метаданных комнаты |
| `js/rolls.js` | рассылка и показ бросков |
| `js/obr.js` | подключение SDK Owlbear (версия закреплена здесь) |
| `js/theme.js` | цвета под тему Owlbear |

## Разработка

```bash
npm test        # тесты правил и кубиков (нужен Node.js 20+)
npm start       # локальный сервер на http://localhost:5173
```

Вне Owlbear лист открывается в «режиме без Owlbear»: всё работает, но броски видны только вам.

`dev/harness.html` открывает лист с подменённым SDK (`dev/obr-mock.js`), «комната» общая для вкладок
браузера — так можно проверить игрока и мастера рядом:
`dev/harness.html?player=p1&name=Иван` и `dev/harness.html?player=gm&name=Мастер&role=GM`.
Чтобы проверить в Owlbear, установите расширение по адресу `http://localhost:5173/manifest.json`
(предварительно поменяв адреса в `manifest.json` на локальные).

При выпуске новой версии увеличьте `version` в `manifest.json` — она же показывается в подвале листа.
